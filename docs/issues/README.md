# Issue Documentation

This directory contains detailed specification files for active development issues.

## Naming Convention

Issue files should be named: `issue-N.md` where N is the GitHub issue number.

Example: `issue-42.md` for GitHub issue #42.

## Purpose

When working on a GitHub issue, a detailed specification file can be placed here to:
- Document requirements and acceptance criteria
- Track implementation notes
- Provide context for AI agents working on the issue

## Usage

Reference this directory in AI instructions:
- `docs/issues/issue-*.md` for active issue files
